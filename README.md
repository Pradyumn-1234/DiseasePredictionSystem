# DiseasePredictionSystem
A Django-based web application for multi-disease prediction (Diabetes, Heart, Parkinson’s) with patient registration and data management system.
🏥 Multi Disease Prediction Web Application 📌 Overview

The Multi Disease Prediction Web Application is a healthcare-based web platform developed using the Django framework. This application is designed to predict multiple diseases and manage patient records efficiently in a centralized system.

It integrates machine learning models to provide early prediction of diseases such as Diabetes, Heart Disease, and Parkinson’s Disease. The system helps users by analyzing medical input data and generating real-time prediction results.

In addition to prediction, the application includes a Patient Registration System that stores patient details in a database. All registered patient records are displayed on the main dashboard, making it easy to view, manage, and track data.

🚀 Features 🧠 Multi-Disease Prediction Diabetes Prediction Heart Disease Prediction Parkinson’s Disease Prediction 📝 Patient Registration System Store patient details securely Structured data entry forms 📊 Dashboard View all registered patients Organized and easy-to-read data ⚡ Real-Time Results Instant prediction using ML models 🌐 User-Friendly Interface Clean UI with responsive design 🛠️ Technologies Used Backend: Django Frontend: HTML, CSS Machine Learning: Python, Scikit-learn Database: SQLite / MySQL ⚙️ How It Works User opens the web application Fills the disease prediction form (Diabetes / Heart / Parkinson’s) Inputs are processed using trained machine learning models System generates prediction result instantly Patient details are stored in the database All records can be viewed on the dashboard 🎯 Objective

The main objective of this project is to develop an intelligent healthcare system that:

Assists in early disease prediction Reduces manual effort in patient data management Provides a centralized platform for storing and analyzing patient records 🔮 Future Enhancements Add more disease prediction modules Improve UI with advanced design and animations Integrate authentication system (Login/Signup) Deploy on cloud for public access Add data visualization dashboards 📌 Conclusion
